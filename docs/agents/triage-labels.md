# Triage Labels

The engineering skills use five canonical triage roles. Local Markdown tickets record the selected role in their `Status:` line.

| Canonical role | Local status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | A maintainer must evaluate the issue |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation or judgment |
| `wontfix` | `wontfix` | Will not be actioned |

Use the canonical value exactly unless this mapping is explicitly revised.
