# 04 — 完成 Windows 端到端回归验收

**What to build:** 将按键周期去重、无选区显示恢复、有效选区翻译和设置页隔离作为一个完整 Windows 用户流程验收。证明新行为可发布，并记录自动化结果、Windows 手工证据、设计偏差和仍待处理的风险。

**Blocked by:** 01 — 按键周期内只激活一次快捷键；02 — 实现无选区显示恢复与有效选区翻译；03 — 隔离设置页并说明快捷键双重行为.

**Status:** ready-for-agent

**Source:** `docs/SDD-shortcut-no-selection-window-restore.md`，覆盖全部 FR/NFR、第 13 节验证策略和 Coding Agent Execution Protocol。

- [ ] 从未翻译、完整成功、流式生成、未完成译文和错误状态触发无选区快捷键时，窗口显示并聚焦且原状态符合设计。
- [ ] 在浏览器、PDF 阅读器或 Word 中选择有效文本后，当前快捷键仍能创建新翻译请求并按现有规则显示结果。
- [ ] 全空白选区、长按快捷键、快速连续选择两段有效文本，以及有效请求运行时后续无选区的边界行为符合设计。
- [ ] 修改并保存自定义快捷键后，新快捷键具备相同双重行为，旧快捷键不再触发。
- [ ] 设置页快捷键隔离、固定窗口和失焦自动隐藏均保持批准行为。
- [ ] `npm test`、`npm run typecheck`、`npm run build`、`cargo fmt --check` 和 `cargo test` 全部通过并记录结果。
- [ ] Windows 手工验收逐项记录环境、实际结果和通过/失败，不以自动化测试替代未执行的桌面检查。
- [ ] 所有实现偏差使用 `DEV-*` 记录并获得必要批准；不存在静默偏差或范围外重构。
- [ ] SDD 作为活文档记录实施版本、验证证据、偏差和剩余工作；若设计未变化，也明确记录无需修订的原因。
